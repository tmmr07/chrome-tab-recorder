# Chrome画面録画拡張機能

## 概要

Chrome上で表示しているWebページの画面を録画するためのChrome拡張機能です。

ブラウザ上の操作内容やWebアプリケーションの動作確認、デバッグ、プレゼンテーション用の記録など、さまざまな用途で利用できます。

## プライバシーについて

本拡張機能では、録画データを外部サーバーへ送信する処理は実装していません。

録画処理および動画ファイルの生成・保存は、利用者のブラウザおよびローカル環境内で完結します。

録画された映像データは、ユーザーが指定した保存先へ直接保存されます。

## 目的

Mac標準の画面録画機能では、動画ファイルのサイズが大きくなりやすく、短時間の録画でもストレージ容量を大きく消費することがあります。

本拡張機能は、Chromeブラウザ上のWebページやWebアプリケーションの表示内容を録画し、より扱いやすいファイルサイズで画面記録を行うことを目的として開発しました。

主な利用例：

- 開発中のWebアプリケーションの動作確認
- プログラムやUIのデバッグ用記録
- 操作手順やチュートリアル動画の作成
- プレゼンテーション資料用の画面記録

## 注意事項

### 動作環境について

本拡張機能は，M1 MacBook Airでの使用を目的として開発したものです。そのため、その他のOS環境では動作確認をおこなっていないため、正常に動作しない可能性があります。また、M1 MacBook Airのディスプレイに搭載されている画面の比率上、録画データをそのまま再生すると、縦横比が合わず、少し潰れた感じになってしまいます。そのため、ターミナル上で以下のコマンドを実行し、mp4（あるいは好みの拡張子）に変換してください。

```bash
ffmpeg -i record.webm \
  -r 60 \
  -c:v h264_videotoolbox \
  -b:v 12M \
  -vf "pad=width=max(iw\,ih*(16/9)):height=max(ih\,iw*(9/16)):x=(ow-iw)/2:y=(oh-ih)/2:color=black" \
  -c:a aac \
  -b:a 192k \
  output.mp4
```

本拡張機能は、利用者自身が権利を有するコンテンツ、または録画が許可されているコンテンツを記録することを目的としています。

以下のような利用は禁止・推奨されません。

- 著作権者の許可なく、動画配信サービスなどのコンテンツを録画・保存する行為

- 他者が権利を持つコンテンツを無断で公開・配布する行為

録画対象のコンテンツについて、著作権、利用規約、その他の権利関係を確認した上で利用してください。
